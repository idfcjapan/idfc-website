# IDFC日本ミャンマー学生会議 — 公開サイトと共同編集

公開サイト: **https://idfcjapan.github.io/idfc-website/**

GitHub Pagesでは `site/` の閲覧ページ・画像・PDFを公開します。`main` への変更はGitHub Actionsが検証・公開します。メンバー編集画面は既存のSitesサービスを使い、保存した日英セットの公開内容をGitHub Pagesが読み込みます。閲覧URLは変わりません。ログイン情報は公開ページへ渡しません。

元サイト: https://idfc-jpn-mmr.jimdofree.com

トップURLの共有プレビューは「お知らせ」ではなく団体名とトップの紹介文を表示します。使用終了の2016年メールアドレスは、全ページ共通のフッターとお問い合わせ欄から削除しています。

2027の概要・年間活動・運営幹部・日本側実行委員・ミャンマー側実行委員・資料・協賛情報は、ひとつのページ内のアンカーで移動できます。上部メニューはページと一緒にスクロールし、横の目次は現在の見出し・紹介メンバーを強調します。「メンバー」の親項目は廃止し、日本側15名と、提供された6枚の画像から確認できるミャンマー側14名（5部署）を独立した大項目で紹介しています。幹部紹介が重複する画像は人数に重複計上していません。2027本会議の計画人数は、日本18名・ミャンマー18名・合計36名を円グラフではなく人数表示で掲載しています。代表挨拶には日本側・ミャンマー側を明記し、日本代表プロフィールと団体組織図の項目は利用者の指示により削除しました。既存の2027子ページURLも同じ構成を表示し、従来の該当箇所から開きます。日本語・英語に対応しています。こじの写真はパンフレット16ページの人物写真に修正しています。

原文を保存した36ページに、提供された2027資料に基づく8ページを追加しています。静的コンテンツは `site/`、公開用ビルドは `dist/client/` と `dist/server/index.js` です。公開ページはサーバーで保存内容を反映したHTMLを返します。

## 制作・保守

## 日英セットの編集・公開

日本語と英語は一組として編集・保存します。外部の翻訳APIや新しいAPIキーは使用しません。ChatGPTへの依頼と編集ファイルには両言語を含め、文章の翻訳はChatGPTまたは手動で行います。言語を切り替えても未保存の内容を保持し、両言語を確認してから「日英をまとめて保存・公開」で一度に保存します。片方だけの内容や空の翻訳はサーバーが拒否します。写真の差し替えは対応する写真を両言語で更新します。

保存内容はD1の一つのレコードに日英セットで格納されるため、保存競合で片方だけ更新されることはありません。ヘッダー・フッターは両言語の全ページ共通です。公開用の `/api/public/content` は保存済みの公開HTMLだけを返し、未公開の編集案・認証情報は返しません。GitHub Pagesは認証情報を送らずにこの内容を取得し、リンクを公開URLへ変換して表示します。写真アップロードは既存R2を使います。

編集画面から保存した変更は、公開ページを再読み込みすると表示されます。この反映にはJavaScriptと既存の編集サービスへの接続が必要です。サービスに接続できない場合は、GitHubに保存された直近の静的ページを表示します。静的ソースを新しくするために、旧サイト全体を `capture-public-pages.mjs` で上書きしないでください。

検証: `npm run test:editor` はCloudflare workerd・一時D1/R2で59項目を確認します。ブラウザーで日英切り替え、写真の共通反映、両言語の確認前の保存防止、一度の保存から日英の閲覧ページへの反映も検証しています。

### メンバーが自分のChatGPTで編集する

ファイルの受け渡しを省く場合は、対応するChatGPT Work／Codexの内蔵ブラウザーで `/edit/` を開いて本人が共有パスワードでログインし、横のチャットに変更を依頼します。サイトの編集ツールが現在の内容を取得し、AIの案を未公開プレビューへ反映します。確認して「保存して公開」を押すまで公開しません。サイト側のAPIキーは不要ですが、各メンバーのChatGPTの利用枠を使います。通常のChromeやChatGPTのWebチャットだけでは、この直接連携は使えません。提供状況・モデル・ワークスペース設定の影響を受けます。

編集画面には連携状態と、選択中の言語・ページ・場所を含む依頼文を用意する補助欄を表示します。ファイル方式は折りたたんだ補助の手順として残しています。

APIキーは不要です。メンバーは既存の共有編集パスワードで `/edit/` にログインし、ページ・言語・場所を選びます。

1. 変更したい内容を普通の言葉で書き、編集用ファイルと依頼文を用意します。現在の未保存の編集もファイルに含まれます。
2. 自分のChatGPTへファイルを添付し、コピーした依頼文を送ります。ChatGPTに編集済みの `.html` ファイルを作成してもらいます。
3. 返ってきたファイルを編集画面で読み込み、プレビューで確認します。「保存して公開」で初めて全員の公開ページに反映されます。

編集ファイルにはページ・場所・保存版の識別コメントが含まれます。別のページや古い版のファイルは読み込めません。パスワードやセッショントークンは含まれません。読み込んだ編集案はサーバーで安全なHTMLに整え、公開前には保存しません。既存のリビジョン照合により、ほかのメンバーが先に保存した内容の上書きを防ぎます。

対応するChatGPTのブラウザーエージェントでは、ログインした編集画面のWebMCPツールで現在の内容を読み取り、編集案をプレビューへ反映できます。非対応のブラウザーでは上記のファイル方式を使います。公開はどちらも画面の「保存して公開」で行います。

通常の文章・写真編集は `/edit/` で行い、「日英をまとめて保存・公開」で反映します。本文と両言語に共通するヘッダー・フッターを日英セットで編集できます。保存内容はD1、アップロード画像はR2に保存し、ソースの再ビルド後も優先して表示します。IDFC2027の互換URLは保存内容を共有します。

ソースの変更にはNode、Python 3とlxmlが必要です。依存関係をインストールし、`npm run build` で公開用Workerと全アセットを作成します。`npm run test:editor` は実際のCloudflare workerdと一時D1/R2を使い、認証・CSRF・競合検出・保存・画像・再起動後の永続性を確認します。

以下は初回取り込み時の手順です。現在の `site/` に対して実行すると後の修正を失うため、再実行しないでください。現在のビルドは `node scripts/build-pages.mjs`（GitHub Pages）または `npm run build`（編集サービス）です。初回の生成処理の記録:

```text
python scripts/inventory.py
python scripts/build.py
python scripts/qa.py
python scripts/qa_interactions.py
python scripts/report.py
```

CSS・JavaScriptは `site/assets/` 内で管理しており、生成処理は上書きしません。Sitesへは `npm run build` 後のWorkerを公開します。`.openai/hosting.json` はDB・BUCKETの論理バインディングだけを定義し、編集パスワードはSitesの秘密環境変数 `EDITOR_PASSWORD` に保存します。パスワード変更後に再公開すると旧セッションは無効になります。実パスワードをソース・公開アセット・ログへ書かないでください。

## 確認が残っている項目

フォームの送信先・バックエンドは未設定です。名前／メール／内容の3必須項目は再現し、「送信」ボタンを無効化しています。メールへの連絡リンクを案内しています。設定前に送信ボタンを有効にしないでください。

元の外部リンクで404が6件、Driveで閲覧権限が必要な埋め込みが2件あります。原URLを保持し、結果を台帳へ記録しています。

375、390、768、1024、1440pxのブラウザー目視・操作QAは未実施です。CSS、HTML、内部参照、JS構文、主要色のコントラストは検証済みです。

HOMEのNEWS先頭には、2027本会議の開催計画、提供された3資料、2026活動記録へのお知らせを追加しています。資料の全48ページは横方向のスクロールスナップ表示です。矢印、ページ番号、キーボード、ページ指定URLに対応し、JavaScript無効時も横スクロールで読めます。メニューは不透明な背景を持ち、閉じる操作・子メニュー・画面幅の変更で状態をリセットします。CSSとJavaScriptのURLには内容に基づくバージョンを付けています。

操作ロジックの1,143アサーションを検証済みです。375・390・768・1024・1199・1200・1280・1440pxのDOMアダプターでイベントとページ幅を模擬する検証で、実ブラウザーの描画・タッチジェスチャーを確認したものではありません。

フッターのFacebookとXは公式SNSリンクに統一し、同じリンク先を持つ旧ウィジェット2件だけを利用者の指示に基づいて除去しています。原文照合ではこの2件を明示的な許可差分として記録し、その他のフッター本文とSNSリンクを全44ページで確認しています。フッターのサイトマップ内リンクの太さは600で統一しています。

1200px以上の画面では、横ナビを14pxの文字と44px以上の操作領域で折り返して表示します。ページ内のタブも選択状態と操作領域を明確にしています。ヘッダーの実際の高さに合わせてアンカー移動と目次の位置を調整します。コンテンツの表示、メニュー、カードのホバーに短いアニメーションを追加し、prefers-reduced-motionに対応しています。アニメーション機能が使えない環境でも内容を表示します。

概要ページの既存Jimdo法人情報と、元のreCAPTCHAに関するプライバシーポリシーは要確認として保存しています。

画像は原URL参照です。URL到達性は確認しています。画像のローカル保存や旧Jimdoからの301は、別途必要な管理設定が揃った際に行えます。

2027資料から追加した画像はローカルに保存しています。2027本会議はBrand Proposalの「計画」として掲載し、募集開始・費用・申込フォームは資料に記載がないため追加していません。資料間のメール、SNS、人数、2026テーマの表記差は `/idfc2027/資料/#source-notes` に保存しています。原PDFは変更せず、サイトでは画面閲覧用の軽量版を提供しています。

サイトのアクセス設定は作成時の本人限定を維持しています。元Jimdoサイトは変更していません。

## 共同編集と今回の表示修正

共有パスワード編集は8時間のHttpOnly・Secure・SameSiteセッションを使用し、すべての保存とアップロードにサーバー認証とCSRF確認を行います。保存はリビジョン照合で他の編集者の変更を上書きせず、失敗時はブラウザー内の作業内容を維持します。画像はJPEG/PNG/WebP/GIFの8MB以下に限定し、HTML保存はスクリプト・イベント属性・危険なURLを除去します。

出典の自動注記・要確認の表示を除去し、グラフを青・水色・ティールの配色へ更新しました。アドバイザーは根本先生・松田先生・カイン先生の3名を同じ形式で表示します。カイン先生の写真は提供資料で確認できなかったため、写真を創作せず頭文字を表示しています。助成2団体・協賛2団体・後援1団体をカード表示し、ホーム下部にも掲載しました。フッターの指定団体名の行は削除しています。
